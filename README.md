## Шаг3. Идем в настройки
Далее идем в настройки нажимаем "шестеренку"
![Шаг 3](3.jpg)
заходим в "Подписки" и в самом низу отмечаем "Сортровать по пингу"
![Шаг 2](4.jpg)
## Шаг 4. Обновляем подписки
Возвращаемся в главное окно HAPP и напротив каждой подписки нажимаем "стрелочки"
(лучше обновляться по WiFi и чем чаще будете обновляться тем актуальнее будет список доступных ВПН серверов, списки обновляются каждый час)
![Шаг 4](6.jpg)
## Шаг 5. Проверяем доступность серверов
Напротив любой из подписок нажимаем "кружок со стрелочкой"
![Шаг 5](7.jpg)
Ждем примерно минуту, две (зависит от интернет соединения), открываем подписку (там появится список доступных серверов, цифры напротив серверов показывают время отклика сервера чем меньше цифра тем скорость соединения выше)
и подключаемся к серверу выбрав его нажатием
![Шаг 5](8.jpg)
Далее проверяем роботу ВПН соединения (нажимаем "Проверить текущее подключение)
![Шаг 5](9.jpg)
Если все хорошо то видим отклик от сервера в милисекуднах 
![Шаг 5](10.jpg)
( можно пользоваться интернет), если же там что-то другое написано значит ВПН туннель не работает
и нужно подключаться к другому серверу
